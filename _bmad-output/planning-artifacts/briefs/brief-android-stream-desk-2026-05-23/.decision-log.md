# Nhật ký Quyết định Thiết kế (Product Brief Decision Log)

- **23-05-2026**: Khởi tạo Mô tả sản phẩm (Product Brief) cho Android Stream Desk.
- **Lựa chọn Công nghệ**: Chọn Tauri v2 và Vue 3 để tối ưu việc chia sẻ mã nguồn giao diện giữa Windows và Android, khai thác API hệ thống tối giản thông qua Rust ở backend, và chạy offline cục bộ hiệu năng cao.
- **Phạm vi MVP**: Tập trung hoàn thiện kết nối thủ công qua địa chỉ IP trong mạng nội bộ và các tính năng mô phỏng phím cơ bản. Tạm hoãn tính năng tự động tìm kiếm kết nối (mDNS) và hệ thống cài plugin để tránh làm phức tạp hóa ứng dụng quá sớm.
